# 控制台设计规格

两页：建图、巡航。深蓝工作台，全宽地图与右侧监看面板；真实 Logo 直接复用平台资产。无宣传语和解释段落。数字使用等宽字体。小车实屏为 **1024×600**（HDMI-1，xrandr 实测），按此尺寸做单屏不滚动布局；更宽的窗口（≥1280px）自动放宽间距与字号，≤820px 退化为单列滚动。

1024×600 版式（实测值）：

- 顶栏 46px、页脚 22px、工作区留白 8px、列间距 8px、右栏固定 292px。
- 左栏：页工具条 36px + 地图面板 708×472；地图可视区 **694×434**，与 RViz 推流尺寸一致（`rviz_size`）。
- 右栏自上而下：现场视频（视频区 278×208.5，保持 640×480 源比例）、IMU（数值 + 48px 三条泳道曲线）、设备状态；巡航页第二块换成巡航任务面板。
- 实时地图与视频一律 `object-fit: contain` 且容器比例与源一致，只有等比缩放，不允许拉伸填满。
- 地图面板右上角：地图/RViz 切换 + 全屏地图；全屏时隐藏右栏，地图可视区变为 994×434。

颜色：背景 #080f1c，表面 #111c2d，边框 #26344a，主色 #387aff，文字 #e8eef8，次级文字 #9baec5，状态绿 #35d59c，危险红 #f56c78。

组件：60px 顶栏、48px 页工具栏、紧凑分段按钮、地图画布、视频、遥测行、可编辑航点列表、速度滑杆、模态表单。所有视频与数值来自真实数据；无数据为 — / 离线。演示模式必须显式显示“演示”。
