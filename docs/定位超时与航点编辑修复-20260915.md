# 定位超时与航点编辑修复（2026-09-15）

## 原因

小车 runtime/logs/robot.log 在 12:58:20 显示：map_server 刚激活，AMCL 尚未收到地图，即收到全局定位请求，打印 `Initializing with uniform distribution` 后发生 SIGSEGV，整个 nav2_container 退出。底盘、雷达和摄像头仍在，所以页面仍连接，却没有地图/定位并显示 ROS 请求超时。

检查车内 nav2_amcl/src/amcl_node.cpp：globalLocalizationCallback 没有检查 active_、map_、pf_、first_map_received_，直接调用 pf_init_model。控制台原先仅以 service_is_ready 判断初始化就绪；服务在 configure 阶段就已存在，不能据此调用。

## 修改

- 控制台自动定位等待 AMCL lifecycle active 且收到地图，取消/切换时退出等待。
- AMCL 加入激活状态、地图、粒子滤波器和空闲栅格检查，过早调用直接返回，避免空指针/空数组访问。
- AMCL Empty 服务无法返回“尚未初始化”状态，控制台在没有收到首个位姿时最多补发两次，不重置已经收敛中的粒子滤波器。
- RViz 状态不再把导航模式一律显示成“巡航中”；按任务、导航就绪和定位状态显示。
- 侧栏航点区域改成只读预览，点击打开居中大窗口。支持 X/Y/朝向修改、上下排序、删除、地图选点、应用与取消；编辑草稿不调用机器人接口。
- 1024×600 屏幕上弹窗宽 900px，高 568px。列表独立滚动，操作栏固定，输入框和排序按钮至少 44px 高。
